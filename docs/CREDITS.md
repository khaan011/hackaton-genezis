# Материалы демо-дневника

Демо-дни и демо-архив Instagram собраны из **настоящих фотографий и записей с открытыми лицензиями** — чтобы показать работу анализа фото и звука на живом материале, а не на картинках, нарисованных под собственные правила. Ваши дни в «Послевкусии» хранятся только в вашем браузере; эти материалы — лишь витрина.

Снимки уменьшены до 1440 px по длинной стороне и переработаны художественными режимами — это производные работы; для CC BY и CC BY-SA указаны авторы и лицензии, производные под CC BY-SA распространяются на тех же условиях.

## Как пересобрать

1. Фото — в `test/assets/real/*.jpg`, записи — в `test/assets/real/music/*.mp3` (128 кбит/с, первые 110 с).
2. `npm run serve`, затем `DEMO_EXPORT=demo/diary.zip FRESH=1 node test/e2e.js` — дни создаются через настоящий интерфейс.
3. Демо-архив Instagram: `node tools/make_ig_demo.js <папка со снимками 1080 px>`.

Шрифты Lora, Montserrat, Anonymous Pro, Unbounded и Caveat — SIL Open Font License.
